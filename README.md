# Calculatorio

Calculatorio is a Unity project combining a resource-and-trade simulation with procedural audio, MIDI input, a layered synthesizer, and a multi-channel sequencer.

## Requirements

- Unity `6000.2.4f1`

## Opening the project

1. Clone this repository.
2. Add the cloned folder in Unity Hub.
3. Open it with Unity `6000.2.4f1` and allow Unity to restore packages and rebuild its local cache.

Only the project source is versioned. Unity-generated directories such as `Library`, `Temp`, `Logs`, and `UserSettings` are intentionally ignored; Unity recreates them locally.
